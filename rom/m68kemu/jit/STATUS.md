## Host validation and performance

- All 2,048 MOVEQ encodings times all 32 CCR states: 65,536 differential cases pass.
- All 63,488 unsupported words select fallback.
- Eight execution fallback scenarios pass: NOP, A-line, RTE, F-line, trace, IRQ,
  unsupported CPU model and disabled cache.
- Bounded ordinary-RAM host step matches registers, prefetch, internal flags,
  function code, read buffer and cycle count. Same-PC mutation preserves the
  prefetched word and observes the changed opcode after refill.
- Separate cache instances and immutable cache hits pass.
- Five CPU-0-pinned synthetic MOVEQ/BRA runs: median interpreter 12.127 ns/step,
  candidate 10.555 ns/step; median per-run ratio 1.147x. Each timed mixed loop has
  2.5 million compiled steps and 2.5 million interpreter fallback steps.
- Runtime code generation is recorded separately (~14–20 ms for all 2,048
  payloads). Warmup is 10,000 calls/steps before timed execution.

This is a synthetic host result, not a representative AROS application speedup.
The payload-only timing is explicitly not compared as a speedup against a full
CPU step. The host adapter assumes nonthrowing ordinary RAM; it is not a native
memory/fault adapter. It is intentionally outside transparent execution.
